免费版md 1.0.1
本地 Markdown 工作台

安装
1. 双击“FreeMD-1.0.1-universal.dmg”。
2. 将“免费版md.app”拖到旁边的“Applications”文件夹快捷方式。
3. 从“应用程序”打开“免费版md”。

这是 macOS 应用，最低系统为 macOS 12，内置 Apple Silicon 与 Intel 两种架构。
接收者不需要安装 Node.js、Swift、Taio 或任何开发工具。

首次打开
本版本使用本机临时签名，没有 Apple Developer ID 签名或公证。
通过网络接收后，macOS 可能提示无法验证开发者。确认文件来自你信任的发送者后，
先尝试打开一次，再到“系统设置 → 隐私与安全性”查看“仍要打开”。
无需关闭 Gatekeeper 或其他系统保护。受组织安全策略管理的电脑可能不允许打开。

转发
直接发送整个 DMG 文件即可，不要只发送应用包内部的执行文件。
DMG 仅包含应用和本说明，不包含制作者的文档、片段、关联备份或本地数据。

功能
• 文档行悬浮时显示关闭按钮；未保存时提示保存、取消或不保存。
• 本地 Markdown / 纯文本 / JSON 文件编辑，多文档切换、文件夹浏览与文件名搜索。
• 编辑 / 双栏 / 预览，大纲跳转、语法着色、查找替换、常用格式快捷操作。
• 离线 GFM 表格、任务列表、代码高亮、KaTeX 数学公式与 Mermaid 图表。
• 本地相对路径图片；远程图片默认不加载。
• 手动收藏剪贴板或选区，复制、插入、置顶与删除片段。
• 13 项内置文本动作，支持撤销；另有正则查找替换。
• HTML 导出（内嵌样式、字体和本地图片）与 PDF 导出。
• TextBundle 目录打开、TextPack/ZIP 中文本导入；导入时保留原压缩包。
• 手动保存、草稿恢复、外部修改冲突提示；UTF-8 / UTF-16 和可识别的 GB18030 文本。

常用快捷键
新建 ⌘N；打开 ⌘O；打开文件夹 ⇧⌘O；保存 ⌘S；另存为 ⇧⌘S；关闭文档 ⌘W。
查找 ⌘F；替换 ⌥⌘F；加粗 ⌘B；斜体 ⌘I；链接 ⌘K。
导出 HTML ⇧⌘E；导出 PDF ⇧⌘P；收藏剪贴板 ⇧⌘V；收藏选区 ⇧⌘C。

数据位置
文档保存在你选择的位置。
草稿、片段与压缩包导入副本位于：~/Library/Application Support/免费版md/
可通过菜单“片段 → 打开本地数据目录”备份；卸载应用不会主动删除这些数据。
请用 ⌘S 保存文档；自动草稿备份不等于写回原文件。

默认打开方式
其他电脑不会自动更改文件关联。若希望用本应用默认打开 Markdown：
在访达选中一个 .md 文件 → 显示简介 → 打开方式 → 免费版md → 全部更改。

范围
这是独立实现的本地功能版，不是 Taio 的源码恢复或完整兼容版。
不包含 iCloud 同步、Taio/JSBox 脚本执行、Siri/Widget 系统扩展或付费功能授权逻辑。
.taioactions 文件可作为 JSON 查看和编辑，不执行其中的动作。
普通文本文件限制为 20 MB；目录列表最多显示 2,000 个受支持文件。
图片相对路径应位于文档目录内部；符号链接不能绕过该目录范围。
