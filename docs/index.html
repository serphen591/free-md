关于免费版md

你可能还想知道。

真的免费吗？需要注册吗？+

当前发布版本可以免费下载使用，无需注册、登录或购买订阅。源代码也已公开在 GitHub，方便查看实现与提交反馈。

文档会被上传到服务器吗？+

应用在本机读写文档，草稿和片段也保存在本机。编辑与预览不需要网络，远程图片默认不加载。你主动打开外部链接时，会通过系统浏览器访问对应网站。

可以替代 Taio 打开我的 Markdown 吗？+

可以。在访达中选中一个 Markdown 文件，打开“显示简介”，将“打开方式”改为“免费版md”，再点“全部更改”。安装包不会自动更改其他电脑的默认应用。

有哪些暂时不支持的功能？+

这是独立实现的本地功能版，不包含 iCloud 同步、Taio / JSBox 脚本运行或系统小组件。支持查看和编辑 .taioactions JSON，但不执行其中的动作。普通文本文件上限为 20 MB。

这次更新带来了什么？+

v1.0.1 新增侧栏文档悬浮关闭按钮。将鼠标移到文档行上，点击右侧“×”即可关闭该文档；未保存的内容仍会出现保存提示。关闭后台文档时，会保留你当前正在编辑的文档。
